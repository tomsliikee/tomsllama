Analyse: CPU-Speicherbandbreite bei 16 GB DDR4 limitierend. Kontext über 4096 Tokens verlangsamt Matrix-Vektor-Multiplikation. Lösung: Schiebefenster mit Erhalt des System-Prompts.
Auf Prozessoren wie dem Intel Core i5-8350U skaliert die Inferenz-Latenz direkt mit der Token-Anzahl im Kontextspeicher. Ein Sliding Context Window trennt ältere Dialogteile transparent ab, sobald das definierte Budget erreicht ist.

List<Message> trimContext(List<Message> history, int maxTokens) {
  final systemPrompt = history.firstWhere((m) => m.isSystem);
  final turns = history.where((m) => !m.isSystem).toList();

  while (estimateTokens(turns) > maxTokens && turns.length > 2) {
    turns.removeRange(0, 2); // Älteste Frage & Antwort entfernen
  }
  return [systemPrompt, ...turns];
}
